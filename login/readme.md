# Sistema de Login

Sistema web desenvolvido na disciplina de Programação Web II para cadastro e autenticação de usuários, utilizando PHP e banco de dados MySQL.

## Funcionalidades

- Cadastro de usuários
- Cadastro de nome, e-mail e senha
- Autenticação de usuários através de e-mail e senha
- Validação das credenciais no banco de dados
- Conexão com banco de dados MySQL utilizando PDO
- Tela de login inspirada na interface antiga do Instagram
- Tela de cadastro de usuários
- Links entre as telas de login e cadastro
- Interface com banners e elementos visuais inspirados em redes sociais

## Tecnologias

PHP, MySQL, PDO, HTML, CSS e Git.

## Objetivo

Este projeto foi desenvolvido com finalidade acadêmica na disciplina de Programação Web II, colocando em prática conhecimentos de PHP, MySQL, PDO, HTML e CSS através da criação de um sistema de cadastro e login de usuários.

## Sobre a interface

A tela de login foi desenvolvida como exercício de estudo e possui elementos visuais inspirados na interface antiga do Instagram.

O projeto não possui vínculo com o Instagram ou com a Meta. As marcas, logos e elementos visuais pertencem aos seus respectivos proprietários.
