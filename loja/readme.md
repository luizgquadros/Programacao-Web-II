# Loja

Sistema web desenvolvido na disciplina de Programação Web II para cadastro, gerenciamento e exibição de produtos, utilizando PHP e banco de dados MySQL.

## Funcionalidades

- Cadastro de produtos
- Cadastro de nome, descrição e valor
- Upload de várias imagens para cada produto
- Listagem dos produtos cadastrados
- Visualização dos detalhes de cada produto
- Exibição das imagens dos produtos
- Conexão com banco de dados MySQL utilizando PDO
- Interface responsiva com tema escuro

## Tecnologias

PHP, MySQL, PDO, HTML, CSS e Git.
