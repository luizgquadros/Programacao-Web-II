# Programação Web II

Repositório com os projetos desenvolvidos na disciplina de Programação Web II, feitos em PHP com banco de dados MySQL.

## Projetos

- [Sistema de login](login/): cadastro e autenticação de usuários. A tela de login é uma réplica da tela de login do Instagram, na versão antiga, feita para praticar HTML, CSS e PHP.
- [Sistema de loja](loja/): cadastro de produtos com várias imagens e listagem dos produtos cadastrados.

Cada pasta tem seu próprio README com a descrição detalhada, o banco de dados e as instruções de execução.

## Sobre a tela de login

O visual da tela de login foi inspirado na interface antiga do Instagram e foi reproduzido apenas como exercício de estudo de front-end. Este projeto não tem vínculo com o Instagram nem com a Meta, e a marca e o design originais pertencem aos seus respectivos donos.

## Tecnologias

PHP, MySQL, PDO, HTML, CSS e Git.

## Requisitos

- PHP 8 ou superior, com a extensão `pdo_mysql` ativada
- MySQL 8

## Estrutura do repositório

```
Programacao-Web-II/
  login/    Sistema de login e cadastro de usuários
  loja/     Sistema de loja com produtos e imagens
```
